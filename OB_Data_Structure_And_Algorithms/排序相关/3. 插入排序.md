
#### **一句话解释**：

- `0 ~ i` 范围已经被保证有序，将`i + 1`位置从右到左移动至左数不再更小的位置插入，然后`i++`进行下一轮插入

#### **正确性解释**：

- 与选择/冒泡排序相同，核心都是维护一个已经排序完毕的范围，这里维护的是`0 ~ i`范围的升序

- 与选择/冒泡排序的区别在于，插入排序不再找最大/最小数
	
	- 而是直接拿到边界的后一个数，将它插入到排序完毕的范围中，同时该边界也自动被这个后一个数的插入过程给拓展
	
	- 每次插入过程，都保证新数（即后一个数）进入排序完毕范围有序，一直拓展到n - 1时即可保证整个数组有序

- 通过将不断交换的方式将新数插入有序数组

	- 核心在于，若我们在遍历过程中遇到了“临时最大值”，通过不断后移，可以保证该最大值总会在下一次交换中继续后移，从而进入排序完毕范围
	
	- 若没遇到“临时最大值”，则说明该值在当前遍历范围之后，那么可以保证在之后的某一次`j++`中，会无视那一次比较的较小值，`j`后移到“临时最大值”开始交换，那么就进入了上述"遇到"逻辑，保证找到

#### **代码示例**：

```
void BubbleSort(vector <int>& nums)
{
	if (nums.empty() || nums.size() < 2) return; // 空检查
	
	for (int i = nums.size() - 1; i > 0; --i) // i: i ~ n - 1范围视为已经排序完毕的范围
	{
		for (int j = 0; j < i; ++j) // 从 0 开始到 i - 1， 不断将更大的元素向后移动
		{
			if (nums[j] > nums[j + 1])
				swap(nums[j], nums[j + 1]); // 后移一位更大元素
		}
		// 内层循环结束后，保证 0 - i - 1 范围内的最大元素被移动至i位置
	}
}
```
