
####  **一句话解释**

- 在 `i ~ n - 1` 范围上寻找最小值，与`i`位置交换，并在 `i + 1 ~ n - 1` 范围上继续

#### **正确性解释**：
	
- 核心是通过`i`不断拓展“已排序完毕”范围的边界：

	- 第一次拓展，找到数组最小值，放在0位置；

	- 第二次拓展，找到数组第二最小值，放在1位置；
	
	- 循环往复，即可完成排序

- 通过交换，防止数组元素的信息丢失

- 维护一个`minIndex`，在每次寻找最小值前设置为`i`，若`i`位置本身为最小值则与自身交换；

- 寻找最小值过程中，每次遇到比当前索引值`nums[minIndex]`更小的`nums[j]`，就将`minIndex`设置为`j`来更新，遍历完毕后交换 `i` 位置 和 `minIndex` 位置的元素

- 由于每次都会遍历完 `i ~ n - 1` 的整个范围，并且之前的第`0` - 第`i - 1`最小值都被按顺序放入 `0 - i - 1` 范围内，所以可以保证每次都能找到第`i`最小值
	

#### **代码示例**：

```
void SelectSort(vector <int>& nums)
{
	for (int minIndex, i = 0; i < nums.size(); ++i)
	{
		// i: 0 - i - 1 范围视为当前已经排序完毕的范围
		// minIndex: 当前除去已排序范围内的所有数中的最小值的索引
		
		minIndex = i; // 从i位置开始寻找，若“临时最小值”为自身则交换自身
		
		for (int j = minIndex + 1; j < nums.size(); ++i) // 在剩余范围内寻找最小值
		{
			if (nums[j] < nums[minIndex])
			{
				minIndex = j; // 若找到更小值，更新索引
			}
		}
	
		swap(nums[i], nums[minIndex]); // 将找到的“临时最小值”与当前要拓展的已排序边界交换
	}
}
```
